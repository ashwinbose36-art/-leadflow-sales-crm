# LeadFlow Sales CRM Dashboard

> Next-Gen AI Sales Acceleration & Pipeline Management Platform

Live Demo: **[https://ashwinbose36-art.github.io/-leadflow-sales-crm/](https://ashwinbose36-art.github.io/-leadflow-sales-crm/)**

---

## 🌟 Key Features

- **Executive Sales Dashboard**: Real-time revenue metrics, active pipeline stats, conversion rates, and revenue trend charts powered by Chart.js.
- **Leads Directory**: Comprehensive lead management with status tags, real-time search filtering, CSV export, and dynamic lead creation.
- **Deals Pipeline Kanban Board**: Visual deal tracking across Qualified, Proposal Sent, Negotiation, and Closed Won stages.
- **Modern Responsive Design**: Built with Tailwind CSS, Google Inter typography, and Google Material Symbols icons. Light and dark mode support included.

---

## 🚀 Quick Start Local Setup

Run a simple HTTP server in the repository root directory:

```bash
python -m http.server 3030
```

Open `http://localhost:3030` in your browser.
